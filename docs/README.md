# Tyr documentation

Tyr is a dependently-typed deep learning framework for Lean 4: tensor shapes are
tracked in the type system (dimension mismatches are compile-time errors), while
computation runs on libtorch through a C++ FFI layer. These guides explain each
component of the library: what it is for, how it is built, and how to use it.

Two kinds of documentation exist:

- **These guides** — hand-written, per-component, with architecture notes and
  verified usage examples. Start here.
- **API reference** — generated by [doc-gen4](https://github.com/leanprover/doc-gen4)
  from the Lean sources (see `docbuild/`). Use it for exhaustive symbol lookup.

## Contents

### Foundations

- [Getting started](getting-started.md) — dependencies, build, environment,
  tests, running examples and GPU parity suites.
- [Tensors and the torch FFI](core/tensors.md) — `Shape`, the shape-indexed
  tensor type `Tensor σ`, pure specification arithmetic, and checked native
  adapter boundaries.

## Conventions in these guides

- Code examples are reconstructed from real call sites and labeled with their
  source; signatures were verified against the Lean sources at the commit
  where each guide was written.
- Source citations use `path:line` (e.g. `Tyr/Torch.lean:564`).
- Guides describe intent and key APIs; the doc-gen4 reference remains the
  source of truth for exhaustive symbol documentation.
