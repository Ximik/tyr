A lineage-aware branching trajectory

This note follows one variable-cardinality state through two split events. The figure and the account below are derived from Tyr's exported trajectory, including the particle identities and parent–child relations recorded during execution.

Tyr research preview · July 2026

Scope

This is a target-conditioned mechanism trace, not a learned molecular sample. A hand-written predictor is given a fixed three-atom water endpoint and supplies coordinate targets, label logits, and split propensities to the ordinary BranchingFlows generator. No trained network is loaded or evaluated.

The example therefore tests a narrower claim: Tyr can advance continuous and discrete particle state, change cardinality, retain runtime lineage across those changes, and serialize the resulting trajectory without reconstructing correspondences in the plotting code.

One state, two splits

The run begins with one masked particle and uses 33 equally spaced states over t ∈ [0,1]. The first split occurs in the interval (0.03125, 0.0625]; the second occurs in (0.25, 0.28125]. Population size consequently changes from one to two and then from two to three.

At a split, the source identity ends and new child identities begin at the same coordinate. The exported data does not add display offsets to separate coincident children. Their later separation is a property of subsequent state updates, not of the renderer.

Reading the lineage

The initial identity p1 persists through step 1. Event 1 replaces it with p2 and p3. Event 2 later replaces p2 with p4 and p5; p3 remains live. This is why the final state contains p3, p4, and p5, rather than three copies of one ambiguous identifier.

What “target-conditioned” means here

The predictor used for this trace can inspect the fixed endpoint. For each current particle it returns a coordinate target and concentrated label logits derived from that endpoint. While the current population is too small, it also assigns a positive split propensity to one particle. This explicit construction is useful for isolating the generator from the problem of fitting a predictor.

The generator still performs its ordinary forward-time operations: it advances the coordinate and label processes, converts the split propensity into a rate over the current time interval, samples a split count, applies the event, and records the result. The separation below is therefore the important one.

The exported data

The JSONL file begins with a schema row, followed by one row for every particle in every recorded state and one row for each event. State rows contain both array position and stable identity. Event rows make the parent–child relation explicit.
